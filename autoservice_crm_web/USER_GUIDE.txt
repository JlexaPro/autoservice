AUTOSERVICE CRM — Руководство пользователя

1. Главная
- Карточки KPI за день.
- Быстрые кнопки: добавить заявку, клиента, напоминание, открыть планер.
- График загрузки сервиса за месяц с листанием месяцев.

2. Заявки
- Просмотр, фильтры, открытие карточки заявки.
- Создание новой заявки вручную.

3. Клиенты
- Список клиентов.
- Кнопка «Добавить клиента» ведет на отдельную карточку создания.
- Карточка клиента: комментарии, метки, теги, история, связанные машины и заявки.

4. Машины
- Карточка авто.
- Добавление истории работ (сотрудник, описание, комментарий).

5. Планер
- Дневная доска по постам сервиса.
- Drag & drop, resize, двойной клик по свободному слоту для создания записи.
- Автоназначение поста/мастера, быстрые шаблоны работ.

6. Напоминания
- Список напоминаний.
- Создание напоминания через отдельную форму.
- Кнопки: Выполнить, Позвонить, Отправить СМС (по шаблону).

7. Заказ-наряды
- Список, создание и карточка заказ-наряда.
- Добавление работ и запчастей с расчетом суммы/себестоимости/прибыли.
- Смена статуса, автоматические follow-up при закрытии.
- Экспорт заказ-наряда в PDF.

8. Финансы
- Отчет по периоду: выручка, прибыль мастеров, прибыль сервиса, средний чек.
- Топ прибыльных клиентов, выручка по типам работ.
- Выгрузка Excel.

9. Сотрудники
- Список сотрудников.
- Карточка сотрудника: ФИО, роль, ДР, телефон, ставка, комментарии.

10. Настройки
- Рабочие часы и шаг сетки планера.

Советы:
- Все даты вводите в формате календаря в формах.
- Для полей с подсказками можно вводить часть значения и выбирать из выпадающего списка.
- Если при переносе визита появляется ошибка занятости — выберите другой слот/пост/мастера.
